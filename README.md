# CV — Luis Fernando Real Jaimes

Static CV website. Bilingual (ES/EN). Designed for GitHub Pages deployment.

## Local preview

Just open `index.html` in a browser.

## Add your photo

Place a `profile.jpg` (portrait, ~300x350px) in this folder.

## Deploy to GitHub Pages

```bash
git init
git add .
git commit -m "feat: initial cv"
gh repo create inglfr/cv --public --push --source .
# Then go to repo Settings → Pages → Branch: main → / (root) → Save
```

Your CV will be live at: **https://inglfr.github.io/cv**
